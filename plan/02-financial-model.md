# 02 — The 5-Year Financial Model

Every number here is a planning assumption, not a promise. The assumptions are listed
so you can check them against reality monthly and re-forecast. **When actuals diverge
from plan by >30% for two consecutive months, re-run this model with real numbers.**

## Core unit economics (the atoms everything is built from)

| Variable | Value | Basis |
|---|---|---|
| Price (founding) | $147/mo | Under-cuts cheapest credible competitor tier; trivial vs. one commission |
| Price (standard, mo 4+) | $197/mo | Raise after 10 testimonials |
| Price (team plan, Y2+) | $397–$597/mo | 3–10 agents per account |
| ARPU assumption | Y1 $230 → Y5 $290 | Mix shifts toward teams |
| COGS per client/mo | $15–$30 | Twilio number $1.15 + SMS ~$0.008/segment (~600 segments), Claude API ~$3–8, infra share ~$5 |
| **Gross margin** | **85%** | Software economics; the whole reason this model was chosen |
| Monthly churn | Y1 5% → Y3+ 3% | Solo agents churn hard; teams don't. 5%/mo = ~46%/yr — brutal but honest |
| LTV (gross profit) | $230 × 0.85 ÷ 0.04 ≈ **$4,900** | At blended 4% churn |
| CAC — manual outreach | $50–$150 | Mostly your time + $30 data tools |
| CAC — referral | ~$150 | One free month per conversion |
| CAC — paid ads (Y2+) | $300–$600 planning | Must be proven, see rules below |
| Payback requirement | < 2 months | You're capital-constrained; long payback = death |
| LTV:CAC floor | 3:1 hard floor, 5:1 target | Below 3:1, the channel gets killed |

## Three scenarios (with honest probabilities)

| | Conservative (~50% likely) | Base (~35%) | Aggressive (~15%) |
|---|---|---|---|
| What happens | First niche partially fails; pivot once; churn stays ~6%; you plateau where organic channels max out | The plan above, executed with normal setbacks | A team/brokerage partnership channel hits in Y2; churn 2.5%; paid ads scale at CAC <$400 |
| Y1 exit MRR | $1,500 | $5,500 | $9,000 |
| Y3 exit MRR | $8,000 | $35,000 | $60,000 |
| Y5 exit MRR | $12,000 | $84,000 | $140,000 ($1.68M run-rate) |
| 5-yr cumulative | $280,000 | $1.9M | $3.5M+ |
| $1M cumulative? | ❌ (but you're 22 with a $150k/yr business and real skills) | ✅ during Y4 | ✅ during Y3 |

**Brutal honesty:** the single most likely outcome for any $0-start business is failure
(~50% here means *not reaching $1M*, not losing money — max realistic loss is a few
thousand dollars and time). What makes this bet good is the asymmetry: downside is
capped near zero (85% margins, $120/mo tooling, kill-gates), and even the conservative
case leaves you at 22 with income most college grads don't have. Do not confuse this
plan's precision with certainty — the precision exists so you can *detect deviation
early*, not because the future is knowable.

## Capital allocation rules

Your $200–400/wk is a fund. It follows: **Experiment → Measure → Kill or Scale → Reinvest.**

| Rule | Value |
|---|---|
| Max total testing budget, months 1–3 | $1,200 (anything beyond this without a paying client = mandatory pivot review) |
| Max spend before first paying client | $400 |
| Max CAC — outreach phase | $150/client |
| Max CAC — paid phase | $500 hard cap; kill any channel >$500 for 2 consecutive months |
| Target LTV | ≥ $4,500 gross profit |
| LTV:CAC | ≥ 5:1 target, 3:1 kill-floor |
| Payback | < 60 days or the channel doesn't scale yet |
| Refund/cancel threshold | If >20% of new clients cancel within 30 days → freeze acquisition, fix onboarding first |
| Ad testing rules (Y2+) | $25–30/day per test · minimum 7 days or $200 before judging · kill ad set at $150 spend with zero qualified leads · max $60/qualified demo booked · never >30% of MRR on ads |
| When to kill an experiment | Predefined metric missed at predefined spend/date — decided **before** the experiment starts, in writing, in the tracking sheet |
| When to double down | Channel produces 3+ clients at ≤ target CAC in 30 days → increase budget 50% (not 5x), re-measure |
| Cash reserve | Never let cash fall below 2 months' opex; 3 months from Y2 |
| The one non-negotiable | Money buys **experiments and systems**, never comfort. No branding, no merch, no office, no $99 courses |

## What moves you between stages (the gates)

| Stage | Gate to advance | Typical timing (base) |
|---|---|---|
| $0 → first $100 | 1 paying client | Day 14–30 |
| $100 → $1,000 | 5–7 clients, <20% early cancel | Day 30–45 |
| $1,000 → $5,000/mo | 22+ clients; one repeatable channel producing 4+/mo; onboarding ≤2 hrs each | Month 6–9 |
| $5k → $10k/mo | 45 clients; VA doing onboarding; churn <5% | Month 12–18 |
| $10k → $25k/mo | Teams >30% of MRR; paid channel at CAC <$500; you out of delivery | Month 18–30 |
| $25k → $50k/mo | Self-serve SaaS live; support ticket rate <0.5/client/mo; ops manager hired | Year 3–4 |
| $50k → $100k/mo | 2nd vertical or enterprise/brokerage tier; sales not founder-dependent | Year 4–5 |
| $100k/mo → $1M+ | This is now a company: the asset value (3–4× ARR) is the wealth, not the monthly checks | Year 5+ |
